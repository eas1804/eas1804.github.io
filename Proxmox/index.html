hetzner.com -> Rescue

zpool import -f -R /mnt rpool

Если имя пула отличается от rpool, проверь его список командой zpool import

Критически важно: перед перезагрузкой нужно правильно отмонтировать и экспортировать ZFS-пул, иначе ядро при старте может отказаться его импортировать!

1. Отмонтируй все датасеты

cd /

zfs unmount -a

2. Экспортируй пул

zpool export rpool

3. Перезагружайся в штатную систему

reboot

KVM-консоль (BusyBox):

Принудительно импортируйте пул rpool:

zpool import -f rpool

Завершите работу initramfs, чтобы система продолжна нормальную загрузку:

exit

Классическая проблема RDP-сессий: Windows пытается быть «умной» и пробрасывает локальную раскладку на удаленный сервер, создавая дубликат.

New-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\Keyboard Layout" -Name "IgnoreRemoteKeyboardLayout" -PropertyType DWord -Value 1 -Force

Ограничение времени сеансов

gpedit.msc

    Конфигурация компьютера → Административные шаблоны → Компоненты Windows → Службы удаленных рабочих столов → Узел сеансов удаленных рабочих столов → Ограничение времени сеанса

  1. Задать ограничение по времени для отключенных сеансов: Включено (Завершение отключенного сеанса: 1 час или 15–30 минут).
  2. Задать ограничение времени для активных, но бездействующих сеансов: Включено (Ограничение бездействующего сеанса: 12 часов).
  3. Завершать сеанс при достижении предела времени: Включено.

Зависание RDP

  1. Отключить блокировку завершения работы приложений (в GPO)

    Конфигурация компьютера -> Административные шаблоны -> Система -> Параметры завершения работы.

    Состояние: Перевести в Отключено (именно Отключено, чтобы система ПРИНУДИТЕЛЬНО гасила зависшие программы при Logoff).

  2. Конфигурация компьютера -> Административные шаблоны -> Компоненты Windows -> Службы удаленных рабочих столов -> Узел сеансов удаленных рабочих столов -> Перенаправление принтеров

    Использовать в первую очередь драйвер принтера удаленного рабочего стола Easy Print

Команды оптимизации реестра Windows

(PowerShell от имени Администратора)

    Настройка таймаутов освобождения ресурсов RDP:

    Set-ItemProperty -Path 'HKLM:\SYSTEM\CurrentControlSet\Control\Terminal Server' -Name 'KeepAliveTimeout' -Value 1 -Type DWord

    New-ItemProperty -Path 'HKLM:\SYSTEM\CurrentControlSet\Control\Terminal Server' -Name 'InactivityTimeout' -Value 1 -Type DWord -ErrorAction SilentlyContinue

  1. Включение авто-завершения зависших процессов для всех профилей пользователей (AutoEndTasks):

    Set-ItemProperty -Path 'Registry::HKEY_USERS\.DEFAULT\Control Panel\Desktop' -Name 'AutoEndTasks' -Value '1'

    Set-ItemProperty -Path 'Registry::HKEY_USERS\.DEFAULT\Control Panel\Desktop' -Name 'WaitToKillAppTimeout' -Value '2000'

    Set-ItemProperty -Path 'Registry::HKEY_USERS\.DEFAULT\Control Panel\Desktop' -Name 'HungAppTimeout' -Value '2000'

  2. Добавление 1С / BAF и службы печати в системный список для принудительной выгрузки (SysProcs): 
    $sysProcsPath = 'HKLM:\SYSTEM\CurrentControlSet\Control\Terminal Server\SysProcs'
if (-not (Test-Path $sysProcsPath)) { New-Item -Path $sysProcsPath -Force }

New-ItemProperty -Path $sysProcsPath -Name '1cv8.exe' -Value 0 -PropertyType DWord -Force
New-ItemProperty -Path $sysProcsPath -Name '1cv8c.exe' -Value 0 -PropertyType DWord -Force
New-ItemProperty -Path $sysProcsPath -Name 'splwow64.exe' -Value 0 -PropertyType DWord -Force
New-ItemProperty -Path $sysProcsPath -Name 'ezvit.exe' -Value 0 -PropertyType DWord -Force

    Чтобы система при закрытии сеанса завершала абсолютно все фоновые программы (не только занесенные в SysProcs), добавьте параметр HonorCurrentUserAppTimeout:

    Выполните в PowerShell от имени Администратора:PowerShell

    # 1. Принудительный учет AutoEndTasks при закрытии RDP-сеанса

    Set-ItemProperty -Path 'HKLM:\SYSTEM\CurrentControlSet\Control\Terminal Server' -Name 'HonorCurrentUserAppTimeout' -Value 1 -Type DWord

    # 2. Игнорирование заблокированных / не отвечающих приложений при Logoff

    Set-ItemProperty -Path 'HKLM:\SYSTEM\CurrentControlSet\Control\Terminal Server' -Name 'PRNoPrompt' -Value 1 -Type DWord

    # 3. Отключение автоматического сохранения состояния сеанса (сброс зависших профилей)

    Set-ItemProperty -Path 'HKLM:\SYSTEM\CurrentControlSet\Control\Terminal Server' -Name 'fResetBroken' -Value 1 -Type DWord

  3. Применение изменений групповых политик:

    gpupdate /force

Приложение Windows App

Отключение HTTP Proxy в Windows App на macOS

Откройте приложение Windows App на Mac.
В левом верхнем углу экрана (в строке меню macOS) нажмите 
Windows App -> Settings... (или нажмите горячие клавиши Cmd + ,).
В левом боковом меню откройте первый раздел — General.
В блоке Connection найдите самый верхний пункт:Use HTTP proxyВыключите переключатель (сдвиньте влево, чтобы он стал серым/неактивным).
Закройте окно настроек (Settings).

Зависший или поврежденный кэш лицензий на клиенте (macOS).

Перед выполнением rm -rf выполните команду, которая ищет запущенный процесс

pgrep -i "Windows App"

Если команда ничего не вывела — приложение полностью закрыто, можно сразу чистить кэш.

Если вывела цифры (PID процесса) — приложение работает в фоне.

Универсальное принудительное завершение

pkill -9 -f "com.microsoft.rdc"

Проверка

pgrep -f "com.microsoft.rdc"

Запускать эту команду нужно при полностью закрытом приложении Windows App.

cd ~/Library/Containers/com.microsoft.rdc.macos/Data/Library/Application Support/

Для более старых версий приложения путь может быть: ~/Library/Containers/com.microsoft.rdc.network-extension/Data/Library/Application Support/)

Найдите и удалите (или переместите на рабочий стол для бэкапа) папку com.microsoft.rdc.macos или содержимое папки Application Support/Microsoft Remote Desktop.

rm -rf com.microsoft.rdc.macos

эта команда:

Удаляет кэш лицензий: Стирает все сохранённые локальные токены RDP (включая застрявшие SSL/CAL-сертификаты, вызвавшие 0xf06).

Сбрасывает конфигурацию: Приложение возвращается к состоянию «только что установлено» — удаляются сохранённые подключения, учетные данные и пользовательские настройки.

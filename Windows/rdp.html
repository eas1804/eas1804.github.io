ВСЕГДА 3 раскладки клавиатры. Не добавлялись лишние раскладки

Классическая проблема RDP-сессий: Windows пытается быть «умной» и пробрасывает локальную раскладку на удаленный сервер, создавая дубликат.

New-ItemProperty -Path "HKLM:\SYSTEM\CurrentControlSet\Control\Keyboard Layout" -Name "IgnoreRemoteKeyboardLayout" -PropertyType DWord -Value 1 -Force

Удаленный сеанс отключен, поскольку отсутствуют доступные серверы лицензирования удаленных рабочих столов, которые могли бы провести лицензирование.

Перейдите в

HKEY_LOCAL_MACHINE\Software\Microsoft\MSLicensing

Удалите подпапки

HardwareID и Store

или 

Windows Registry Editor Version 5.00 

[-HKEY_LOCAL_MACHINE\SOFTWARE\Microsoft\MSLicensing]

Запустите подключение к удаленному столу (mstsc) обязательно от имени Администратора (это нужно один раз, чтобы Windows заново создала ключи в реестре).

Остановка службу лицензирования RDS

Stop-Service TermServLicensing -Force

Запуск службу лицензирования RDS

Start-Service TermServLicensing

Сделать копию TLSLic.edb

Остановка службы занимает 1–2 секунды и не рвет активные RDP-сессии пользователей, которые уже работают на сервере. 
Stop-Service TermServLicensing -Force
Copy-Item -Path "C:\Windows\System32\LServer\TLSLic.edb" -Destination "C:\Windows\System32\LServer\TLSLic.edb.bak"
Start-Service TermServLicensing

Проверить текущий режим лицензирования RDS

(Get-WmiObject -Namespace "Root\CIMV2\TerminalServices" -Class Win32_TerminalServiceSetting).LicensingType 

2	Per Device	Лизензия привязывается к железу/клиенту (вашему Mac).
4	Per User	Лицензия привязывается к учетной записи пользователя.
5	Not Configured	Режим не задан (работает Grace Period).

Проблемы с сервером Лицензиррования

Журнал сервера лицензирования (RD Licensing)

eventvwr.msc ->Applications and Services Logs -> Microsoft -> Windows -> TerminalServices-Licensing -> OperationalТакже

Классический журнал System

(фильтр по источнику TerminalServices-Licensing

Ключевые Event ID, которые стоит искать:

  1. Event ID 21: Ошибка выдачи временной/постоянной лицензии клиенту.
  2. Event ID 1028 / 1029: Сервер лицензирования не смог обновить или предоставить RDS CAL для устройства.
  3. Event ID 1043: Отказ в выдаче лицензии из-за отсутствия свободных CAL или истечения срока действия.

Журнал RDP-хоста (RD Session Host)

На этом же сервере перейдите в журнал самого RDP-сервиса:

Applications and Services Logs -> Microsoft -> Windows -> TerminalServices-RemoteConnectionManager -> OperationalКлючевые Event

  1. ID:Event ID 1004: Terminal Server не может выдать лицензию клиенту (в описании ошибки будет указан имя/MAC вашего Mac).
  2. Event ID 1011: Ошибка проверки лицензии при установке соединения.

Powershell

Get-WinEvent -FilterHashtable @{
    LogName = 'System', 'Microsoft-Windows-TerminalServices-Licensing/Operational', 'Microsoft-Windows-TerminalServices-RemoteConnectionManager/Operational'
    Level = 2, 3 # Error и Warning
} -MaxEvents 30 | Format-Table TimeCreated, Id, ProviderName, Message -AutoSize

Зависший или поврежденный кэш лицензий на клиенте (macOS).

Перед выполнением rm -rf выполните команду, которая ищет запущенный процесс

pgrep -i "Windows App"

Если команда ничего не вывела — приложение полностью закрыто, можно сразу чистить кэш.

Если вывела цифры (PID процесса) — приложение работает в фоне.

Универсальное принудительное завершение

pkill -9 -f "com.microsoft.rdc"

Проверка

pgrep -f "com.microsoft.rdc"

Запускать эту команду нужно при полностью закрытом приложении Windows App.

rm -rf ~/Library/Containers/com.microsoft.rdc.moremac

эта команда:

Удаляет кэш лицензий: Стирает все сохранённые локальные токены RDP (включая застрявшие SSL/CAL-сертификаты, вызвавшие 0xf06).

Сбрасывает конфигурацию: Приложение возвращается к состоянию «только что установлено» — удаляются сохранённые подключения, учетные данные и пользовательские настройки.

Итоговый идеальный однострочник для Mac:

pkill -9 -f "com.microsoft.rdc"; rm -rf ~/Library/Containers/com.microsoft.rdc.moremac

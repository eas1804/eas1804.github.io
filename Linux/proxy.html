Proxy

  1. Установите Squid

    apt update

    apt install -y squid apache2-utils curl -y

  2. Создайте пользователя прокси

    htpasswd -c /etc/squid/passwords proxyuser

  3. Разрешите службе Squid читать файл:

    chown root:proxy /etc/squid/passwords

    chmod 640 /etc/squid/passwords

    Пользователь proxyuser создается только для прокси — системная учетная запись Debian ему не нужна.

  4. Настройте Squid
  5. /etc/squid/squid.conf

    rm /etc/squid/squid.conf

    Для отдельного сервера, предназначенного только для проксирования:

    cat /etc/squid/squid.conf 

    # Порт HTTP-прокси
http_port 3128

# Авторизация по имени пользователя и паролю
auth_param basic program /usr/lib/squid/basic_ncsa_auth /etc/squid/passwords
auth_param basic realm Proxy
acl authenticated proxy_auth REQUIRED

# Разрешенные порты назначения
acl Safe_ports port 80
acl Safe_ports port 443
acl SSL_ports port 443
acl CONNECT method CONNECT

# Запрет доступа к служебным адресам сервера
acl localhost_dst dst 127.0.0.0/8 ::1

http_access deny !Safe_ports
http_access deny CONNECT !SSL_ports
http_access deny localhost_dst

# Доступ только после авторизации
http_access allow authenticated
http_access deny all

# Не кэшировать страницы
cache deny all

    Squid использует программу basic_ncsa_auth для проверки паролей из файла, созданного htpasswd.

  6. Проверьте и запустите службу

    squid -k parse

    ss -tlnp | grep 3128

    Если ошибок нет:

    systemctl enable --now squid

    systemctl restart squid

    systemctl status squid --no-pager

  7. Проверьте работу прокси

    На самом сервере: 

    curl -x http://127.0.0.1:3128 \
  -U proxyuser \
  https://api.ipify.org

    Введите пароль по запросу. В ответ должен отобразиться внешний IP-адрес прокси-сервера.

    Для проверки с другого компьютера замените 127.0.0.1 на внешний IP сервера:

    Если локально работает, а с другого компьютера нет, проверьте входящие правила брандмауэра Debian и панели VPS-провайдера для TCP-порта 3128.

    Важно: при обычном HTTP-прокси логин и пароль между AdsPower и сервером передаются без шифрования. HTTPS-сайты при этом остаются защищены своим TLS-соединением. Если подключение идет через интернет, рекомендую ограничить доступ к порту 3128 по IP-адресу Windows Server или использовать VPN, например WireGuard.

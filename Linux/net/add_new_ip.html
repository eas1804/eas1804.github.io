Добавить дополнитенльный IP 12.132.149.150

  1. Убедитесь, что адрес не добавлен:

    ip -4 addr show dev vmbr0

  2. Добавляем ВРЕМЕННО адрес в 12.132.149.150 интерфейс vmbr0

    ip addr add 12.132.149.150/32 dev vmbr0

  3. Проверьте выход через него:

    curl -4 --interface 12.132.149.150 --connect-timeout 10 https://api.ipify.org

    Ожидаемый ответ:

    12.132.149.150

  4. Добавляем в /etc/network/interfaces

    В секцию iface vmbr0 inet static, 

    iface vmbr0 inet static
	address 12.132.149.175/26
	gateway 12.132.149.129
	bridge-ports eno1
	bridge-stp off
	bridge-fd 0
	post-up /usr/sbin/ethtool -K  eno1 tso off gso off

    Добавляем 

    up ip addr add 12.132.149.150/32 dev vmbr0
down ip addr del 12.132.149.150/32 dev vmbr0
  5. /etc/nftables.conf

    Меняем

    oifname "vmbr0" ip saddr 10.11.11.0/24 masquerade

    на

    oifname "vmbr0" ip saddr 10.11.11.0/24 snat to 12.132.149.150

  6. Проверьте синтаксис и сохранённые строки:

    nft -c -f /etc/nftables.conf

  7. Применить

    nft -c /etc/nftables.conf

  8. Проверка конфига

    grep -A 10 'iface vmbr0 inet static' /etc/network/interfaces

    nft -a list chain ip nat POSTROUTING

    grep -A 8 'chain POSTROUTING' /etc/nftables.conf

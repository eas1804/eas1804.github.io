Восстановление MikroTik hAP ac² через Netinstall

Шпаргалка для чистой установки RouterOS Stable с компьютера Windows. Архитектура роутера — ARM.

Внимание: при описанной чистой установке текущая конфигурация и файлы на роутере удаляются. При необходимости заранее создайте копии .backup и .rsc и перенесите их на компьютер.

1. Скачать Netinstall и пакеты RouterOS

  1. Откройте официальную страницу MikroTik Downloads.
  2. В разделе RouterOS выберите архитектуру ARM и канал Stable.
  3. Скачайте системный пакет RouterOS, дополнительный пакет wireless и утилиту Netinstall Win64. Выбирайте одинаковую версию пакетов и Netinstall.
netinstall64-7.xx.x.zip
routeros-7.xx.x-arm.npk
wireless-7.xx.x-arm.npk

Для hAP ac² вместо wireless можно использовать wifi-qcom-ac (новое меню WiFi, WPA3); одновременно эти пакеты не работают. Для этой инструкции выбран wireless. wifi-qcom для встроенного Wi-Fi hAP ac² не подходит. Версия Wi-Fi пакета должна совпадать с версией RouterOS.

2. Подготовить папку

  1. Создайте, например, C:\MikroTik\Netinstall.
  2. Распакуйте в папку архив Netinstall.
  3. Скопируйте в неё оба файла .npk.

3. Подключить роутер

  1. Соедините компьютер сетевым кабелем напрямую с портом ether1 MikroTik.
  2. При необходимости временно отключите другие сетевые интерфейсы и VPN, чтобы Netinstall выбрал правильное подключение. Интернет и активные соединения при этом могут прерваться.

На этом компьютере физический адаптер Intel используется внешним коммутатором Hyper-V Hyper-lan, а интерфейс Windows называется vEthernet (Hyper-lan). Он уже использовался при успешной установке. Не удаляйте коммутатор: это может нарушить сеть виртуальных машин.

4. Назначить временный адрес компьютеру

Пример: адрес компьютера 192.168.1.10/24, шлюз не нужен. Проверьте адрес:

Get-NetIPAddress -InterfaceAlias "vEthernet (Hyper-lan)" -AddressFamily IPv4 |
    Format-Table IPAddress, PrefixLength, AddressState

Если адреса нет, откройте PowerShell от имени администратора и выполните:

New-NetIPAddress -InterfaceAlias "vEthernet (Hyper-lan)" `
    -IPAddress 192.168.1.10 -PrefixLength 24

Через несколько секунд проверьте состояние адреса: оно должно быть Preferred. Не добавляйте адрес повторно, если он уже существует.

5. Настроить Netinstall

  1. Запустите netinstall64.exe от имени администратора.
  2. Нажмите Net booting и включите Boot Server enabled.
  3. Укажите Client IP address: 192.168.1.20 и нажмите OK.

Адрес клиента должен отличаться от адреса компьютера, но находиться в той же подсети. При ошибке Could not find network interface проверьте активный адрес и подключение, затем при необходимости перезапустите Netinstall.

6. Запустить роутер в режиме Netinstall

  1. Отключите питание роутера.
  2. Зажмите кнопку Reset и, удерживая её, подключите питание.
  3. Продолжайте держать Reset: индикатор сначала мигает, затем горит постоянно, затем гаснет.
  4. Когда индикатор погаснет, отпустите Reset и дождитесь появления роутера в Netinstall.

Это запуск через резервный загрузчик. Если отпустить кнопку во время мигания, будет выполнена другая операция.

7. Выбрать роутер и установить пакеты

  1. В списке Routers/Drives выберите строку RB… со статусом Ready и архитектурой arm. Сверьте MAC-адрес с наклейкой роутера.
  2. Не выбирайте диски компьютера — например, E:\, G:\ или S:\.
  3. Если пакетов не видно, нажмите Browse в разделе Packages и выберите папку с файлами .npk.
  4. Отметьте оба пакета: routeros и wireless.
  5. Для чистой установки снимите Keep old configuration и включите Apply default config.
  6. В поле Key оставьте <use previous key>, если оно показано. Нажмите Install.

8. Дождаться завершения

Не отключайте питание и кабель во время установки. Дождитесь сообщения Installation finished successfully и статуса Done. При выбранном Reboot after installation роутер перезагрузится автоматически; подождите несколько минут.

9. Подключиться после установки

  1. Переставьте кабель компьютера с ether1 на ether2.
  2. Откройте WinBox → Neighbors и выберите роутер по MAC-адресу.
  3. Войдите пользователем admin. Пароль проверьте на наклейке; если не указан, попробуйте пустой. Задайте новый пароль при первом входе.
  4. Заводской адрес обычно 192.168.88.1. При необходимости для подключения по IP временно назначьте компьютеру свободный адрес 192.168.88.10/24.

10. Проверить и завершить

В WinBox откройте System → Packages и проверьте версии routeros и wireless; в Wireless → Interfaces проверьте наличие радиоинтерфейсов. Команды в терминале RouterOS:

/system/package/print
/interface/wireless/print
/ip/address/print

Удалите временный адрес, если он больше не нужен, и включите отключённые адаптеры и VPN:

Remove-NetIPAddress -InterfaceAlias "vEthernet (Hyper-lan)" `
    -IPAddress 192.168.1.10 -Confirm:$false

Настройки MikroTik для мониторинга Zabbix

Исходные данные:

Zabbix Server: 65.21.73.59

SNMP: v2c

Порт: UDP/161

  1. Создать отдельный список адресов:

    /ip firewall address-list add \
    list=zabbix-snmp \
    address=65.21.73.59 \
    comment="Zabbix Server"

  2. Создать SNMP community только для чтения:

    /snmp community add \
    name="<СЛУЧАЙНЫЙ_COMMUNITY>" \
    addresses=65.21.73.59/32 \
    security=none \
    read-access=yes \
    write-access=no

  3. Включить SNMP:

    /snmp set enabled=yes contact="admin" location="Balzaka68"

  4. Разрешить SNMP в firewall перед общим правилом DROP:

    /ip firewall filter add \
    chain=input \
    action=accept \
    protocol=udp \
    dst-port=161 \
    src-address-list=zabbix-snmp \
    comment="SNMP from Zabbix" \
    place-before=[find where comment="other DROP!!!!"]

  5. Отключить стандартный community public:

    /snmp community remove [find name="public"]

  6. Проверить конфигурацию:

    /snmp print

    /snmp community print>

    /ip firewall address-list print where list=zabbix-snmp

    /ip firewall filter print

    Ожидаемое состояние: 

    SNMP enabled: yes
Community: отдельный, read-only
Адрес community: 65.21.73.59/32
Firewall: UDP/161 разрешён только от Zabbix Server
Community public: отсутствует
SSH-пользователь MikroTik для работы Zabbix не нужен. Zabbix подключается к маршрутизатору через SNMP.

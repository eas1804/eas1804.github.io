    Доступ по SSH ключу

    1. Создать ключ в Powershell

    ssh-keygen -t ed25519 -f "$env:USERPROFILE\.ssh\company.key" -C "company Mikrotik"

    для 6й версии нужен ключ rsa

    ssh-keygen -t rsa -b 3072 -f "$env:USERPROFILE\.ssh\company.key_rsa" -C "company Mikrotik"

    2. Загрузите и импортируйте публичный ключ

    Подключитесь к роутеру через WinBox и перетащите файл NAME.pub в окно Files, в корневой каталог. Затем в терминале RouterOS выполните:

    /user ssh-keys import public-key-file=NAME.pub user=admin

    Проверьте, что ключ привязан к нужному пользователю:

    /user ssh-keys print detail

    Важный момент: при стандартном значении password-authentication=yes-if-no-key после добавления ключа вход этого пользователя по паролю через SSH отключается. Поэтому до импорта оставьте открытой сессию WinBox или другой рабочий способ доступа. На вход через WinBox этот параметр SSH не распространяется.
